CyberGuard-AI
CyberGuard-AI — это локальный Telegram-бот ассистент по кибербезопасности и пентестингу, построенный на базе Node.js, фреймворка Telegraf и локальной LLM-модели Qwen2.5:7b через Ollama.
Проект разработан с фокусом на повышенную информационную безопасность (ИБ) и защищен от методов социальной инженерии и атак типа Prompt Injection (перехват контекста).
Основные особенности
 Полная локальность и приватность: Бот работает без отправки ваших данных на внешние облачные API (все запросы обрабатываются внутри вашей машины через Ollama).
 Хардварный уровень защиты (Anti-Prompt Injection): Встроенный текстовый фильтр перехватывает вредоносные инструкции разработчика/дебаг-режимы еще до отправки в модель.
 Двухуровневый жесткий SYSTEM_PROMPT: Модель изолирована директивами, запрещающими раскрывать алгоритмы работы, системные инструкции и скрытые метаданные.
 Прозрачное логирование: В консоль выводится полный аудит входящих команд, текста пользователей и ответов бота для быстрого мониторинга угроз.
Стек технологий
 Runtime: Node.js (ES Modules)
 Framework: Telegraf (Telegram Bot API)
 LLM Core: Ollama (Qwen2.5:7b)
 Environment: Dotenv
Требования к окружению
Перед запуском убедитесь, что у вас установлены:
1. Node.js (версии 20+)
2. Ollama с развернутой моделью qwen2.5:7b
Инструкция по установке и запуску
1. Клонируйте репозиторий:
git clone https://github.com/kalbekaziz-svg/CyberGuard-AI.git
cd CyberGuard-AI
2. Установите зависимости:
npm install
3. Настройте переменные окружения:
Создайте файл .env в корневой директории проекта:
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
OLLAMA_URL=http://localhost:11434
4. Запустите бота:
node index.js
Безопасность и архитектура
Проект реализует концепцию Defense in Depth (глубоко эшелонированная оборона) на уровне конфигурации бота:
 Реализован строгий лимит истории диалога (MAX_HISTORY), чтобы избежать переполнения контекста модели.
 Все сессии пользователей изолированы друг от друга с помощью Map().
