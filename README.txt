🛡️ Hybrid AI Assistant with Built-in IDS & DoS Protection
Высокопроизводительный, отказоустойчивый гибридный Telegram-бот на базе Node.js и локальной LLM (Ollama). Спроектирован с упором на информационную безопасность, защиту аппаратных ресурсов сервера (Anti-DoS) и строгое разграничение ролей.
🚀 Основные фичи
 * Гибридная архитектура:
   * Deterministic Mode (Игры): Запросы по игровым крафтам обрабатываются через статический словарь (GAME_WIKI), полностью минуя LLM. Это гарантирует 0% галлюцинаций и нулевую нагрузку на CPU.
   * AI Mode (Кибербезопасность / Медицина): Сложные контекстные запросы перенаправляются на локальную модель qwen2.5:7b.
   * Vision Mode: Распознавание изображений и документов с помощью мультимодальной модели llava.
 * Система защиты от DoS и Flood атак (Anti-DoS):
   * Active Requests Lock: Блокировка параллельных запросов от одного пользователя до завершения текущей генерации.
   * Content Filtering: Жесткий лимит на длину входящих сообщений (макс. 800 символов).
   * Execution Timeout: Принудительный разрыв зависших генераций через AbortController (25 секунд) для защиты процессора от перегрева.
 * Встроенная IDS (Система обнаружения вторжений):
   * Автоматическое распознавание паттернов социальной инженерии (например, попытки выдать себя за разработчика).
   * Автоматическое начисление варнов нарушителям.
 * Панель администратора (SOC):
   * Управление доступом прямо из интерфейса Telegram с помощью Reply-команд (/warn, /mute, /unmute, /status).
   * Удаленный безопасный выгруз исходного кода по команде /getcode только для подтвержденного OWNER_ID.
 * Профессиональное логирование: Раздельные потоки логов (консоль, combined.log, error.log) на базе Winston с фиксацией инцидентов безопасности.
🛠️ Технологический стек
 * Runtime: Node.js (ES Module syntax)
 * Framework: Telegraf (Telegram Bot API)
 * Local LLM Engine: Ollama (qwen2.5:7b, llava)
 * Logger: Winston
 * HTTP Client: Node-Fetch
⚙️ Установка и запуск
1. Требования
 * Установленный Ollama
 * Загруженные локальные модели:
   ollama run qwen2.5:7b
   ollama run llava
2. Настройка окружения
Создайте файл .env в корневого каталоге проекта:
BOT_TOKEN=your_telegram_bot_token
OLLAMA_API_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:7b
OLLAMA_VISION_MODEL=llava
OWNER_ID=7562776557
3. Запуск
npm install
node index.js

👑 Руководство администратора (SOC Commands)
Все команды применяются в качестве ответа (Reply) на сообщение нарушителя в чате бота:
 * /warn — Выдать предупреждение. При достижении 3/3 варнов аккаунт автоматически уходит в мут.
 * /mute — Немедленная ручная блокировка пользователя.
 * /unmute — Полная разблокировка пользователя с обнулением варнов.
 * /status — Просмотр текущих ограничений и счетчика варнов пользователя.
